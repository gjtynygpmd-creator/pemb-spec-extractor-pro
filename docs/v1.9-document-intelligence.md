# v1.9 Document Intelligence Engine

## Why this release exists

The v1.8.1 extraction review identified a structural weakness: the worker relied on PDF embedded text and regex. Drawing sheets could contain readable information visually while their text layer was sparse, spatially scrambled, or misleading.

## Routing

1. Extract native PDF text and block coordinates.
2. Score the usefulness of the text layer instead of using a raw character threshold.
3. OCR low-signal pages and high-value drawing sheets at 220 DPI.
4. Classify the combined page representation.
5. Run the text/value engine.
6. Run coordinate-aware extraction against the original PDF text blocks.
7. Validate, normalize, rank, and conflict-check candidates before saving them.

## Safety changes

- Load regexes use short same-line windows.
- Wind speed no longer treats generic/nominal wind labels as basic wind speed.
- S1/Ss require seismic/spectral context.
- Fractional roof slopes are normalized correctly.
- Low-signal pages are no longer counted and skipped.

## Future extension

A cloud vision/document AI provider can be inserted into the OCR-assisted path for selected pages while retaining the same structured candidate and validation pipeline.
